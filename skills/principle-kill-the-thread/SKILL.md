# Kill the thread

Prefer close, merge, or explicit drop over another open loop.

**Why:** Capture without expiry is the failure this plugin exists to fight. A plugin that makes it easier to file more items is a worse GBrain, not a better jstack.

**Pattern:** Before adding a page, a follow-up, or an Action line, ask whether an existing thread can end instead. If live mail already settled it, kill the compiled item. If two pages cover the same decision, update one and leave the other. An explicit drop on a page beats a polite "maybe later" with no date.

**Does not change:** A new fact that will be asked again and has no home. That still earns Capture. Trivia still does not.
