# Cite or it is inference

A claim without a slug, gmail id, event id, or URL is inference. Label it.

**Why:** Pretty synthesis hides disagreement. The next pass cannot re-check a vibe.

**Pattern:** After each load-bearing sentence, you should be able to point at the artifact you read this session. If two sources disagree, show both. Do not average them. Null results get listed as findings, not omitted.

**Does not change:** Obvious local context the user just stated in this chat. Still do not launder that into a cited "fact" on a page without saying it came from the user.
